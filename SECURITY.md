# Güvenlik Politikası

## Desteklenen Sürümler

Bu projenin yalnızca en son sürümü güvenlik güncellemeleri alır.

| Sürüm | Destekleniyor |
|-------|---------------|
| 0.0.x | Evet          |

## Güvenlik Açığı Bildirimi

js-udf-tools projesinde bir güvenlik açığı bulduğunuzu düşünüyorsanız, lütfen GitHub Issues üzerinden **özel** olarak bildirmeyin. Bunun yerine, aşağıdaki yöntemlerden birini kullanın:

1. **E-posta**: Proje sahibine doğrudan e-posta ile bildirin
2. **GitHub Security Advisory**: [GitHub Security Advisories](https://github.com/softkoop/js-udf-tools/security/advisories/new) sayfasından özel bir rapor oluşturun

### Ne Beklemelisiniz

- Bildiriminiz en kısa sürede incelenecektir
- Açığın doğrulanmasının ardından bir düzeltme geliştirilecek ve yayınlanacaktır
- Güvenlik açığı kamuya açıklanmadan önce size bilgi verilecektir
- Katkınız (isteğe bağlı olarak) güvenlik duyurusunda takdir edilecektir

## Kapsam Dışı

Aşağıdakiler güvenlik açığı olarak değerlendirilmez:

- Zaten kamuya açık olarak bilinen güvenlik açıkları
- Kullanıcının kendi ortamındaki yanlış yapılandırmadan kaynaklanan sorunlar
- Bağımlılık paketlerindeki kritik olmayan güvenlik açıkları (bunlar `npm audit` ile takip edilir)
